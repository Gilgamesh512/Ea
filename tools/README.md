# Security Testing & Hash Analysis Tools (Optional / Lab Only)

Thư mục này dành cho việc lưu trữ các công cụ kiểm thử mật khẩu và giải mã băm ngoại tuyến (như Hashcat, John The Ripper) phục vụ các bài thực hành an toàn thông tin hoặc đánh giá mật khẩu nội bộ:

- `tools/hashcat-*/`
- `tools/john-*/`

> **Lưu ý:** Các công cụ này chứa mã nhị phân nặng và các mẫu kiểm thử đã được cấu hình trong `.gitignore` để tránh đẩy lên GitHub làm phình repository hoặc bị hệ thống quét mã độc chặn.
